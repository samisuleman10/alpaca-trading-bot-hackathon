# How much of the market the live system can actually see

Generated by `scripts/compare_feeds.py` from 2021-07-01 to 2026-08-27, both ends inclusive.

The backtest is measured on the **SIP** feed -- the consolidated tape,
every US exchange merged. The live system can only use **IEX**, a single
exchange, because that is what the free tier gives us in real time. This
table is the size of the gap between the two.

**IEX minutes** counts the minutes that exist on IEX at all. A minute in
which nothing traded on IEX produces no bar -- and a missing bar is a
hole, not a quiet minute.

**A damaged session** is one where IEX is missing 20 or more minutes.
That number is the strategy's volume-comparison window, so a hole this
size is guaranteed to silence the rule rather than merely thin it.

## Days IEX saw nothing at all

- **2025-03-10** -- no IEX bars on 10 of 10 symbols (SPY, QQQ, IWM, AAPL, MSFT, NVDA, AMD, TSLA, META, AMZN).

A full session with no data is not a thin day, it is an outage. The
live system would have seen nothing, formed no view, and traded
nothing. That is the correct behaviour and it must be the *designed*
behaviour: a trader that treats an absent feed as a calm market is a
trader that acts on a stale price.

## What this means for the strategy

1. **The volume rule does not mean the same thing on both feeds.** IEX
   sees roughly one fiftieth of the trading. "This minute was 1.2 times
   busier than usual" is measured against a base that small, so it is a
   far noisier judgement live than in the rehearsal. The threshold has
   to be swept separately on each feed, and a value that only works on
   SIP is a value we cannot use.

2. **The day's average price is an estimate on IEX, not a measurement.**
   It is computed from a few per cent of the volume. The distance from
   it -- the entire entry signal -- inherits that error.

3. **Expect fewer trades live than in the backtest, before any other
   effect.** Holes silence the rule for a full window each. The
   150-trade power floor has to be checked against the IEX count, which
   is the number of trades we would really get, not the SIP count.
